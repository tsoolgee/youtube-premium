# יוטיוב פרימיום

נוצר ע"י **צול גאה** · [TSOOLGEE.UK](https://tsoolgee.uk)

תוסף לכרום (וגם סקריפט לטמפרמונקי) שנותן את מה שיש ב-YouTube Premium. אין בו כפתורים או תפריטים משלו בתוך יוטיוב: כל פיצ'ר מופיע במקום שבו יוטיוב מציג אותו למנויי Premium.

| פיצ'ר | איפה |
|---|---|
| בלי פרסומות | שקוף – פרסומות בסרטונים ובפיד פשוט לא מופיעות |
| בלי הצעות Premium | שקוף – בלי חלונות "נסו את Premium" ובלי אזהרת חוסם פרסומות |
| ניגון ברקע | שקוף – ממשיך כשעוברים לשונית או ממזערים, בלי "עדיין צופים?" |
| חלון צף | אוטומטי כשיוצאים מהלשונית באמצע ניגון – בטלפון (m.youtube) כברירת מחדל, ובהגדרות אפשר להפעיל גם במחשב (Chrome 134 ומעלה, עם אישור של הדפדפן) |
| מהירויות עד פי 4 | ⚙ ← מהירות הפעלה (ובמובייל ⚙ ← מהירות): הסליידר עד 4, כפתור 3.0 של Premium עובד, ו-Shift+&gt; של יוטיוב ממשיך מעל 2 |
| איכות מרבית | נבחרת אוטומטית; ⚙ ← איכות כרגיל |
| הורדה | כפתור "הורדה" של יוטיוב (וגם ⋮ ← הורדה; במובייל כפתור "הורדה" בסרגל הפעולות): חלון "איכות ההורדה" עם **כל האיכויות שיש לסרטון** (עד 4K אם יוטיוב מציע) ושמע בלבד – M4A או MP3, הודעת "יורד..." עם פס התקדמות, והכפתור עצמו מראה "יורד" ואז "הורדת" |
| הגדרות | תוסף: בלחיצה על האייקון בסרגל של כרום. טמפרמונקי: ⚙ בנגן, או ⋮ במובייל |

עובד ב-www.youtube.com, ב-m.youtube.com וב-music.youtube.com.

## הורדות

- **בדפדפן:** הווידאו והשמע יורדים ומתאחדים לקובץ MP4 אחד בתוך הדפדפן, בלי תוכנה חיצונית. ההורדה בחלקים של 4MB בארבעה מסלולים במקביל, עם ניסיונות חוזרים שמתאפסים בכל התקדמות – כך שחיתוכים מקריים של חיבור מסונן (נטפרי) לא מפילים אותה.
- **MP3:** יוטיוב לא מגיש MP3, ולכן פס הקול מפוענח ומקודד מחדש בדפדפן (320kbps כברירת מחדל, ניתן לשינוי ל-128/192/256) עם תג ID3 של שם השיר והאמן. זה לוקח זמן ויש בו אובדן איכות – M4A הוא המקור כמו שיוטיוב שלח.
- **סרטון כבד לזיכרון:** אם הדפדפן לא מצליח להחזיק את הקובץ, ההורדה ממשיכה אוטומטית באיכות אחת מתחת.
- **100% בדפדפן:** אין שום שרת חיצוני. הבקשות יוצאות רק ליוטיוב עצמו, והקובץ נבנה ונשמר מהלשונית – לכן צריך להשאיר אותה פתוחה עד סוף ההורדה.

## התקנה

**תוסף לכרום:** להוריד את `youtube-premium-extension.zip` מה-Releases ולחלץ (או להוריד את הריפו) → `chrome://extensions` → מצב מפתח → "טעינת פריט לא ארוז" → התיקייה (`extension/`).

**טמפרמונקי:** להתקין את [`userscript/youtube-premium.user.js`](userscript/youtube-premium.user.js).

## קרדיטים

הקידוד ל-MP3 נעשה ב-[LAME](https://lame.sourceforge.net/) (lamejs, `src/vendor/lame.min.js`, LGPL) – הקובץ נשמר כמו שהוא, עם הרישיון שלידו.

## מגבלות

- ההורדה בדפדפן משתמשת בלקוח visionOS של יוטיוב (כמו yt-dlp). כשיוטיוב משנה משהו היא עלולה להפסיק לעבוד עד לעדכון.
- חסימת פרסומות היא מלחמה מתמשכת עם יוטיוב. אם סרטונים נתקעים בטעינה – לכבות "חסימה מוקדמת" בהגדרות.
- את קטלוג המוזיקה של Premium באפליקציות, "1080p Premium" וסנכרון הורדות בין מכשירים אי אפשר לתת – הם נקבעים בשרתים של יוטיוב.

## פיתוח

- הקוד ב-`src/` (הפיצ'רים ב-`src/features/`). `python build.py` בונה את `extension/`, את `userscript/youtube-premium.user.js` ואת `dist/youtube-premium-extension.zip`.
- `CONTRACT.md` – הממשקים בין הרכיבים.
- בדיקות: `node test/<name>.test.js`, ודף שמדמה את נגן יוטיוב ב-`test/index.html` (להגיש עם שרת סטטי מקומי).
